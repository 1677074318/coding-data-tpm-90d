# Coding 数据管线 TPM｜90 天工作设想

李丹的候选人价值与 90 天验证方案在线版。页面聚焦：

- Agentic Coding 数据策略演进；
- Bad Case 归因与证据门禁；
- 两个核心问题对应的四项可验证工作假设；
- 端到端数据管线；
- 30 / 60 / 90 天阶段目标、前提假设和决策 Gate；
- 可量化验收指标。

这是无构建依赖的静态单页，可直接通过 GitHub Pages 发布。

## 独立材料

- `/badcase-workbench/`：Bad Case 工程化归因与验证闭环；
- `/agent-coding-strategy/`：从百川阶段代码数据策略到 Step Agentic Coding 策略；
- `/90-day-value/`：提前开放 HC 后的 30/60/90 天价值验证计划。

## 本地预览

```bash
python3 -m http.server 8080 --directory coding-data-tpm-90d
```

然后打开 `http://localhost:8080`。
